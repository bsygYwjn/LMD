## 重跑

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm test:all
pnpm audit
```

浏览器验收需要另行安装的 Playwright 与浏览器，使用方法见 `tools/player-acceptance/README.md`。它们不属于运行时依赖。

## 明确边界

- 模拟移动视口不等于实体 Android/iOS 验收；Safari 原生 HLS、实体设备手势和后台行为尚未现场覆盖。
- 真实位图编码测试覆盖 PGS；未提供 VobSub/DVB 完整样片与独立批准像素参考。
- 未执行有效弹弹play凭证的线上联调；不使用真实用户密钥做测试。
- 解析器内存测试不等于十台设备和完整 FFmpeg 管线长期压力测试。
- 入口 JS 仍约 1.06 MB（gzip 326 KB），构建有大块提示；后续可独立评估按媒体板块拆包，当前未扩大这次修复范围。
