# LMD 播放核心接口说明

所有接口都复用现有的认证与文件夹权限：会话标识不能替代授权校验，权限失效后停止继续提供分片。管理类接口只允许本机访问。

## 1. 媒体元数据

### `GET /api/media/:id/info`

返回带版本的完整媒体元数据，供前端做能力检测与轨道选择。

```json
{
  "mediaId": "6fe1151d86dd35376f35",
  "version": 1,
  "sourceSignature": "4230741:2026-09-11T05:09:00.871Z",
  "container": "matroska",
  "duration": 60.023,
  "startTime": 0,
  "bitRate": 563882,
  "tracks": [
    { "id": "0", "index": 0, "type": "video", "codec": "h264", "profile": "High", "level": 30,
      "pixelFormat": "yuv420p", "bitDepth": 8, "width": 640, "height": 360, "frameRate": 25,
      "codecString": "avc1.64001e", "hdr": false, "attachedPicture": false },
    { "id": "1", "index": 1, "type": "audio", "codec": "aac", "profile": "LC", "channels": 1,
      "sampleRate": 44100, "language": "jpn", "title": "Japanese", "codecString": "mp4a.40.2" }
  ]
}
```

规则：

- 时长是浮点秒，不取整。
- 允许多条视频、音频、字幕轨道；封面附件不会被当作主视频。
- 文件未变化但元数据版本落后时重新分析；分析失败不会标记为完整元数据。
- 记录签名与磁盘不一致时重新分析，返回的签名始终对应当前文件。

## 2. 播放会话

### `POST /api/media/:id/playback-sessions`

请求体：

```json
{
  "capabilities": { "mse": true, "nativeHls": false, "h264": true, "aac": true,
    "direct": { "0:1": true }, "tracks": { "0": { "mse": true }, "1": { "mse": true } } },
  "startTime": 21.5,
  "audioTrackId": "1",
  "videoTrackId": "0",
  "fallbackLevel": 0,
  "preferNativeHls": false
}
```

响应（201）：

```json
{
  "sessionId": "2306b7ab-...", "generation": 1, "mediaId": "6fe1...",
  "strategy": "REMUX", "transport": "mse",
  "plan": { "video": { "track": { }, "action": "COPY", "codec": "h264" },
            "audio": { "track": { }, "action": "COPY", "codec": "aac" },
            "reason": "保留编码，仅调整容器与轨道", "fallbackLevel": 0 },
  "duration": 60.023, "requestedTime": 21.5, "timeOffset": -0.08,
  "sourceStart": 21.42, "readyEnd": 23.42, "state": "ready", "eof": false, "error": null,
  "url": "/api/playback-sessions/2306b7ab-.../manifest.m3u8?generation=1",
  "heartbeatSeconds": 10,
  "buffer": { "aheadSeconds": 30, "backBufferSeconds": 30, "maxBufferBytes": 67108864 },
  "encoder": null
}
```

- `timeOffset` 是**由实际时间戳求得**的会话偏移，原片时间 = 传输时间 + 该偏移。
- `sourceStart`/`readyEnd` 描述当前处理窗口在原片时间轴上的位置。
- 同一浏览器每个会话独立计数；相同配置的请求会共享同一个处理任务。

### `PATCH /api/playback-sessions/:id`

```json
{ "position": 32.4 }                       // 位置更新与续租
{ "seekTime": 90, "generation": 1 }        // Seek
{ "audioTrackId": "2", "generation": 1 }   // 切换音轨
```

- 位置更新只延长租约，不改变代次。
- Seek 与切轨会递增 `generation`；携带过期 `generation` 的请求返回 `409 STALE_SESSION`。
- 切换音轨时若目标轨道已不存在，回退到默认音轨而不是失败。
- 同一播放器的冷 Seek 与切轨复用这个接口和原 `sessionId`；只有初次播放、会话过期或播放策略降级时重新 `POST`。
- 客户端将 120 ms 内的连续更新合并为末值并串行提交。前一代响应晚到时只同步服务端代次，不会重新接入旧媒体源。
- 切换代次会立即移除当前消费者；若旧 FFmpeg 没有其他消费者，服务端等待其退出后才挂接新管线。
- 网络重试先以仅含 `position` 的 `PATCH` 续用当前代次；只有收到 `410 SESSION_EXPIRED` 才创建替代会话。

### `DELETE /api/playback-sessions/:id`

释放该消费者的引用。最后一个消费者离开后，处理进程会在释放宽限期（默认 5 秒）后停止。

### 分片与清单

| 地址 | 说明 |
|---|---|
| `GET /api/playback-sessions/:id/file?generation=N` | DIRECT 策略的原文件 Range 传输 |
| `GET /api/playback-sessions/:id/manifest.m3u8?generation=N` | 只列出已完成分片的 HLS 清单 |
| `GET /api/playback-sessions/:id/init.mp4?generation=N` | fMP4 初始化段（含原片精确时长） |
| `GET /api/playback-sessions/:id/:n.m4s?generation=N` | 第 n 个媒体分片 |

错误码：

| code | HTTP | 含义 |
|---|---|---|
| `SESSION_EXPIRED` | 410 | 会话不存在或已释放 |
| `STALE_SESSION` | 409 | 代次已过期（旧地址、旧 Seek 结果） |
| `SEGMENT_EXPIRED` | 410 | 分片已被缓存回收 |
| `SOURCE_CHANGED` | 409 | 原文件已被替换，会话与管线已释放 |
| `SESSION_OWNER` | 403 | 其他设备的会话 |
| `SOURCE_MISSING` | 404 | 原文件不存在 |
| `TOOLS_UNAVAILABLE` | 503 | FFmpeg 未就绪 |
| `CACHE_FULL` | 507 | 播放缓存空间不足 |
| `PIPELINE_TIMEOUT` | 504 | 处理进程长时间无输出 |
| `STREAM_LIMIT` | 503 | 并发播放会话达到上限 |
| `NO_DECODER` / `NO_TRANSPORT` | 422 | 没有可用解码或传输能力 |

## 3. 位图字幕

### `GET /api/media/:id/bitmap-subtitles/:trackIndex?start=..&duration=..`

返回该窗口内的位图字幕显示列表：

```json
{ "trackIndex": 2, "codec": "hdmv_pgs_subtitle", "start": 0, "duration": 35,
  "canvas": { "width": 1920, "height": 1080 }, "total": 812,
  "cues": [ { "start": 1.0, "end": 4.0, "width": 1920, "height": 120,
              "url": "/api/media/6fe1.../bitmap-subtitles/2/cue-00001.png" } ] }
```

- 每张图片是按需从原文件解码的透明 PNG，首次请求会解码整条轨道并建立时间索引。
- `start` 与 `end` 都是原片时间；同一时刻可能返回多条（多层字幕）。
- 图片地址只能取规范文件名，过期后返回 `410 SEGMENT_EXPIRED`。
- 不支持的轨道返回 `404 NOT_BITMAP_SUBTITLE`；空轨道返回 `422 NO_BITMAP_CAPTIONS`。

## 4. 播放设置

### `GET /api/settings/video-playback`（仅本机管理）

```json
{ "settings": { "cacheMaxBytes": 10737418240, "cacheTtlSeconds": 21600, "aheadSeconds": 30,
    "backBufferSeconds": 30, "heartbeatSeconds": 10, "leaseSeconds": 45, "releaseGraceSeconds": 5,
    "noOutputSeconds": 30, "cleanupSeconds": 60, "maxBufferBytes": 67108864, "encoder": "auto" },
  "status": { "sessions": 0, "pipelines": 0, "cacheBytes": 0, "sessionsCreated": 0, "sessionsReleased": 0,
    "pipelinesCreated": 0, "pipelinesReleased": 0, "cacheHits": 0, "fallbacks": 0,
    "seeks": 0, "audioTrackSwitches": 0, "bytesGenerated": 0 },
  "sessions": [ { "id": "2306b7ab", "generation": 1, "position": 21.5, "ageSeconds": 12, "idleSeconds": 2,
    "hasPipeline": true, "transport": "mse" } ] }
```

`PATCH` 接受上述字段的子集，越界或“租约小于心跳两倍”会返回 `400 INVALID_SETTINGS`。运行设置页的“视频播放缓存与会话”卡片使用该接口。

## 5. 弹幕

| 接口 | 说明 |
|---|---|
| `GET /api/settings/danmaku` | 返回 `{ appId, configured, environmentManaged }`，**绝不返回 AppSecret** |
| `PATCH /api/settings/danmaku` | 保存 `appId`/`appSecret`，或 `{ clear: true }` 清除；仅后端文件保存 |
| `POST /api/media/:id/danmaku/match` | 需要 `consent: true`；返回候选或自动绑定 |
| `POST /api/media/:id/danmaku/binding` | 人工确认绑定，优先于自动匹配 |
| `POST /api/media/:id/danmaku/comments` | 取回标准化后的聚合弹幕 |

供应商调用：

- `POST https://api.dandanplay.net/api/v2/match`
- `GET https://api.dandanplay.net/api/v2/comment/{episodeId}?withRelated=true`
- 签名 `base64(sha256(appId + timestampSeconds + pathname + secret))`，`pathname` 不含查询串。
- 文件哈希为前 16 MiB 的 MD5，在服务器计算，不上传原视频。

行为规则：

- 未同意联网、未配置凭证、外部服务失败、限流或配额不足都不会阻塞视频播放。
- 只有供应方明确返回唯一精确匹配时才自动绑定；多候选或番名/季/集数冲突时只展示候选。
- 绑定关联原文件版本，文件被替换后重新判断。

## 6. 真实浏览器自检

| 接口 | 说明 |
|---|---|
| `GET /api/player-test/target` | 返回首个可播放媒体与最近一次报告摘要 |
| `POST /api/player-test/report` | 接收浏览器自检报告并写入 `data/playback-test/browser-report.json` |
| `GET /api/player-test/report` | 读取最近一次报告 |

这三个接口只在服务以 `LMD_PLAYER_TEST=1` 启动时存在，否则返回 `404 PLAYER_TEST_DISABLED`；即使启用也要求本机管理权限。
