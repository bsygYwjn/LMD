# 局域网上传与下载回归

测试仅使用临时目录、独立 HTTP 端口及独立 `LMD_DATA_DIR`。服务端集成测试会读取本机 LAN 地址，使用该地址验证普通用户权限，避免回环地址管理员特例掩盖问题。不会修改实际共享媒体、用户、分类或访问控制开关。

`pnpm test:all` 自动发现下面的 `*.test.mjs`；也可用项目的 `runtime/node.exe` 单独运行。

| 测试文件 | 验证内容 |
| --- | --- |
| `server/downloads-files.test.mjs` | ZIP 使用 STORE 并逐文件读取；原字节和中文路径；配套文件去重；短期链接的身份绑定、过期和下载时权限复核；下载独立并发配额；空目录授权；未发布文件过滤；共享移除保留原件；扫描失败回滚；目录联接拒绝。音乐父目录封面必须单独授权。 |
| `server/downloads-zip64.test.mjs` | 65,536 个零字节条目越过 ZIP 的 16 位条目计数上限；验证自动生成 ZIP64 EOCD 和 locator、64 位记录数及偏移、兼容 EOCD 的饱和值。测试归档约 8.2 MiB，源流逐个打开。 |
| `server/transfer-permission-migration.test.mjs` | 从版本 11 状态启动，先按旧根目录别名迁移分类及用户直接目录授权，再发现空目录。旧用户默认不能上传。迁移后根 bucket 精确匹配，重新分类不会扩大到子目录或空兄弟目录；只有本次新建的一、二层目录继承父分类；重启不重复展开别名。 |
| `server/transfer-directories.test.mjs` | 空根目录及空子目录上传目标；可导航祖先与可写 bucket 分离；目录分类继承；五类文件格式；扫描期间再次发布会触发补扫。 |
| `server/upload-service.test.mjs` | 24 项隔离用例：分块及完整 SHA-256、重复/错误块、前缀拒绝、任务隔离、取消/过期、空间预留及并发、排他发布竞争、提交期间撤权、持久 pending、故障恢复及分组改目标事务。 |
| `server/transfers-integration.test.mjs` | 五个库通过实际 HTTP API 上传并索引；保留多层路径；用户授权撤销；重启续传和错误前缀拒绝；跨用户任务隔离；原件下载及 SVG CSP。 |
| `server/music-library.test.mjs` | 即使 ALAC 已有 FLAC 兼容副本，下载仍返回原始 ALAC 字节；中文下载文件名；HEAD、Range、416；既有音乐解析及权限回归。 |
| `server/photos-library.test.mjs` | 含脚本、事件属性及外部资源引用的 SVG，经 file、preview、thumbnail 返回原文时必须带无脚本、无同源特权的 sandbox CSP；既有图片库回归。 |
| `server/reading-library.test.mjs` | 阅读库在新增上传及空目录能力后，保留原有格式、权限、封面、回滚及原文件读取行为。 |

`tools/library-browser-regression.mjs` 已扩展为五导航，覆盖其他文件和窄屏显示，并保留音乐、阅读、图片原有交互回归。`tools/transfers-browser-regression.mjs` 启动隔离状态的真实 HTTP LAN 服务，验证 `crypto.subtle` 与 `crypto.randomUUID` 均不可用时 Worker 哈希、文件夹输入、跨板块队列、音乐持续播放、刷新重选续传、带歌词的浏览器原生 ZIP 下载，以及 SVG 三种原文 URL 的脚本及外部请求隔离。

`tools/files-admin-browser-regression.mjs` 使用隔离服务和临时目录回归“其他文件共享”管理页：空路径可以打开 Windows 目录选择操作、选择成功会通过真实 API 保存、取消或添加失败保留输入、纠正路径后可用 Enter 重试。浏览器测试只模拟系统选择窗口的返回值，目录注册、校验和持久化均走真实后端。

构建和浏览器测试可使用 `pnpm build --outDir dist-transfer-preview`、环境变量 `LMD_FRONTEND_DIST` 指向该目录；浏览器套件需要可用的 Playwright Chromium，`LMD_PLAYWRIGHT_MODULE` 可指定已安装模块的文件 URL。服务 `LMD_WEB_DIR` 允许测试实例使用隔离前端产物。

ZIP64 的编码由 `yazl` 按文件大小、偏移和条目数量自动选择；已实测条目数量阈值，没有生成 100 GiB 文件或下载完整超大归档。跨根目录改目标及复制失败恢复在临时目录、故障注入中验证，没有实测两块物理磁盘间迁移，也没有人为填满实际磁盘。断电恢复用持久化清单模拟关键中断状态，不宣称完成真实断电、外置盘拔出或长时间 NAS 网络故障测试。
