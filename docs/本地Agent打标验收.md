## 使用边界

自动化回归使用隔离模拟数据。2026-09-22 已按用户要求为真实「アニメ」目录执行联网查证与打标，未向真实库写入测试标题。该目录按作品和独立特典分为 79 组。日常使用时，在服务器电脑的本机 Agent 中发送管理页复制的任务，即可继续处理所选范围。

来源由 Agent 提供，LMD 校验格式、证据是否齐全和保护规则，不独立查证来源内容。标准季目录可合并为作品组；不明确的目录组织及季集对应应标待确认。其他候选功能未实现。
