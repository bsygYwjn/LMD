# LMD：局域网本地媒体中心

LMD 运行在 Windows 10/11 电脑上，把电脑里的本地视频、无损音乐、电子书和表格直接分享给同一局域网内的 Android、iPhone、iPad、Windows 和 macOS 浏览器。项目不需要域名，不会把文件上传到互联网。

当前发布版本为 `V0.2_Beta`。

当前版本默认采用简单的免登录模式，也可以在本机控制端一键开启局域网访问控制：每个六位数字访问码对应一个用户，并通过“全年龄”“R-18”等文件夹分类分配观看范围。管理页面和管理接口始终只接受服务器电脑本机访问。

## 一键启动

1. 双击项目根目录中的 `启动LMD.vbs`，启动过程不会出现 CMD 窗口。
2. LMD 会进入 Windows 系统托盘并弹出控制面板，其中包含本机管理网页快捷按钮、观看端地址和二维码。
3. 手机或平板扫描二维码即可打开观看端；之后左键点击托盘图标可随时再次打开控制面板。
4. 控制面板和托盘右键菜单都能快速关闭或启动共享服务。关闭共享服务后 8096 端口停止监听，但托盘控制器继续运行，点击“启动共享服务”即可恢复。
5. 在管理端分别添加视频、音乐或阅读目录，然后执行对应扫描。视频缩略图、音乐封面与歌词缓存只写入 `data/cache`；电子书和表格不会被解包、转换或修改。
6. 如需限制访问范围，在管理端“运行设置”点击“开启访问控制”。开启后侧栏才会显示“访问控制”：先把视频、音乐或阅读文件夹归类，再生成六位访问码并勾选允许该用户访问的分类。回到“运行设置”一键关闭即可恢复免登录简洁版，分类和用户配置会保留。
7. 如需登录 Windows 后自动运行，在管理端“运行设置”点击“开启开机自启”。
8. 视频较多时，可在“运行设置”点击“开启 12 小时加速”，把重封装从单任务临时提升为最多 3 个并行任务；到期会自动关闭。

项目已经自带 Node.js、FFmpeg 和 ffprobe，普通使用不需要另行安装编程工具。如果 FFmpeg 尚未就绪，可以在管理端“运行设置 → MEDIA ENGINE”一键自动安装最新版（联网从 gyan.dev 下载并解压到 `tools/ffmpeg/bin`，带进度显示、可取消；已安装时按钮会先检查更新，仅下载新版）。

## 访问规则

### 观看端

- 访问控制关闭时，局域网设备打开 `http://服务器局域网IP:8096` 后直接进入媒体库，与旧版体验一致。
- 访问控制开启时，局域网设备只需输入六位数字访问码，不再填写用户名；每个访问码只对应一个用户，该用户只能看到控制端授权分类里的文件夹。
- 新配置会预置“全年龄”和“R-18”分类，也可以新建、改名或删除分类。每个视频、音乐或阅读文件夹最多归入一个自建分类；没有手动归类的文件夹会自动进入系统的“未分类”分类，可以直接授权给访问码用户。
- 文件夹权限在服务端同时应用于目录、缩略图、音视频/阅读文件 Range 直传、字幕、字体、封面和歌词接口，不能通过手工拼接地址绕过。
- 登录使用 30 天 HttpOnly 会话 Cookie；六位访问码通过 scrypt 派生后保存，不会把明文写入 `data/state.json`。连续 5 次失败会临时限制登录 5 分钟。
- 控制端重置访问码、禁用或删除用户时，该用户的现有登录会立即失效。

### 管理端

- 管理地址固定为 `http://127.0.0.1:8096/admin`，只在服务器电脑上使用。
- 服务端根据网络连接来源判断是否为本机，只接受 `127.0.0.1`、`::1` 和 Windows 的 IPv4 回环地址。
- 局域网设备即使手工输入 `/admin` 或直接调用添加目录、管理端扫描、重封装等管理接口，也会收到 `403` 拒绝响应。观看端仅开放扫描已有媒体目录所需的专用接口。
- 管理端没有密码，打开本机地址即可管理媒体库、访问用户和运行设置；服务器本机也是隐式管理员，不会被观看端登录功能锁住。

LMD 使用局域网 HTTP，访问控制可以阻止未授权浏览和直链读取，但不能代替 HTTPS。请勿把 8096 端口映射或转发到公网；Windows 防火墙首次询问时建议只允许“专用网络”，访问码也应通过可信方式发送。

## 音乐库与无损播放

- 音乐与视频使用彼此独立的根目录，并按真实磁盘目录层级浏览；访问码权限同样覆盖目录、封面、歌词和音频直链。
- 支持 MP3、AAC/M4A、FLAC、WAV、AIFF、OGG/Opus、APE 和 WavPack。浏览器不易直接播放的无损格式会生成经过 PCM 一致性校验的 FLAC 兼容副本，不生成新的 AAC/MP3 有损副本。
- 封面优先读取文件夹中的 `cover`、`folder`、`front`、`album` 或“专辑封面”图片，其次读取音频内嵌封面；原图和音频文件不会被改写。
- 歌词支持同名 LRC、增强 LRC、内嵌同步歌词和普通内嵌歌词。完整播放器提供滚动歌词、播放队列、顺序/单曲/随机模式，目录间切换后由底部迷你播放器继续播放。
- 移动端使用浏览器原生 `<audio>` 与 Media Session，支持锁屏封面、耳机按键和后台连续播放；具体锁屏按钮由浏览器和操作系统决定。

## 阅读库、电子书与 Excel 预览

- 阅读库用一套目录同时管理电子书和表格，观看端顶部可切换“视频 / 音乐 / 电子书”，阅读页可进一步筛选“全部 / 电子书 / 表格”。支持浏览器前进、后退、刷新和带 `section=reading` 的深链接。
- 电子书支持 PDF、EPUB、MOBI、AZW/AZW3、FB2、CBZ 和 TXT。PDF 提供分页、缩放、适合页面/宽度、旋转、目录与会话内密码；其他电子书由锁定提交的 Foliate JS 打开，支持目录、分页/滚动、字号、行距和主题。
- 表格支持 XLSX、XLS、XLSM、XLSB、CSV 和 ODS。文件在模块 Worker 中解析，工作表标签按需读取，并使用虚拟化网格展示大表；单元格只按文本显示，宏永不执行。
- 表格在线预览上限为 64 MiB，TXT 为 16 MiB。图表、图片、数据透视表、条件格式、复杂视觉样式、公式重算和编辑不在快速预览范围内；遇到超限或加密文件可下载原文件后本地打开。
- 阅读进度和排版偏好使用带文件大小与修改时间的浏览器本地键保存，文件替换后旧进度自动失效，不会跨设备同步。打开阅读页时，正在播放的音乐会继续由全局迷你播放器播放。
- 压缩书籍设有条目数、声明解压总量和单条目体积限制；严格 CSP 会阻止书籍脚本、远程资源和对象嵌入。EPUB 字体去混淆在局域网 HTTP 下使用内置 SHA-1，仅用于该格式算法。

## 自动扫描与刷新

- 自动扫描开关集中在本机管理端的“视频目录”区域，默认开启。服务端每 30 秒统一扫描一次已添加的视频、音乐和阅读目录；新增、删除或改名的文件会自动反映到观看页。
- “立即刷新”会马上执行一次扫描并更新文件列表，适合刚复制完视频时使用。
- 自动扫描开关是整个 LMD 服务共用的设置，并会保存到 `data/state.json`；只有服务器电脑上的管理端可以修改。
- 多台设备不会各自重复扫描：同一时间只运行一个服务端扫描任务。观看端只能手动刷新已有目录，不能修改自动扫描设置、添加目录、修改作品代号或执行重封装等本机管理操作。

## 目录层级、网页作品代号与分级菜单

- 管理端会按视频实际所在文件夹列出作品组。每个文件夹只需填写一次作品名和季度。
- LMD 自动从 `[01]`、`E01`、`EP01`、`S01E01`、`第01话` 等常见写法识别集数；无法识别时按文件名自然排序编号。
- 观看端会按已添加视频目录的真实父子层级逐级显示文件夹；同一层的子文件夹和直属视频会一起出现，文件夹嵌套多层也不会被压平。
- 直接包含视频的文件夹仍可使用网页作品代号，视频代号格式固定为 `作品名 - S01E01`。
- 代号只存在于 LMD 的状态数据和网页中，不会重命名磁盘上的视频、外挂字幕或字体，也不会影响缩略图和兼容副本。

## 开机自启

- 开关位于本机管理端的“运行设置”。
- 开启后，每次登录 Windows，LMD 会启动共享服务并驻留系统托盘，不会自动弹出管理网页或控制面板。
- 关闭开机自启会移除 LMD 在当前 Windows 用户启动目录中的入口，不会删除项目或媒体库。
- 如果以后移动整个 LMD 文件夹，请在移动前关闭开机自启，移动完成后重新开启，让启动路径更新到新位置。

## 字幕支持

LMD 支持以下文本字幕：

- SRT：由浏览器原生字幕轨显示。SRT 本身只有时间和文字，不包含 ASS 那样的字体、位置和动画信息。
- ASS / SSA：由 JASSUB 和 libass WebAssembly 渲染，可以保留字体样式、位置、描边、淡入淡出、移动和动画标签。
- 内嵌字幕：扫描视频时自动提取内嵌的 SRT、ASS 和 SSA。MKV 等容器中的内嵌字体附件也会提取并提供给 ASS/SSA 渲染器。

外挂字幕可以放在视频同一目录，支持 `.srt`、`.ass`、`.ssa`。同目录字体支持 `.ttf`、`.otf`、`.ttc`、`.woff`、`.woff2`。例如：

```text
电影.mkv
电影.zh-CN.ass
电影.en.srt
MicrosoftYaHei.ttf
```

重新扫描会重新读取外挂字幕和字体，即使视频文件本身没有变化；同名字幕内容更新后，已打开的观看端也会重新加载。字幕与视频完整文件名不同时，单视频文件夹会关联同目录字幕，多集文件夹会按 `[01]`、`E01`、`第01话` 等集数标记安全匹配；集数无法唯一判断时不会自动乱配。

字幕和字体只在播放时叠加，不会烧录进视频，也不会修改原始文件。图片型字幕（例如 PGS）暂不支持。

## 直传、格式、HDR 和重封装

服务端支持 HTTP Range，浏览器只请求正在播放的文件片段，可以拖动进度条，不需要先下载完整视频。媒体库会扫描 MP4、MKV、MOV、M4V、WebM、AVI、TS、M2TS、MTS、MPG、MPEG 和 FLV。

能被 LMD 扫描不等于所有浏览器都能直接解码。实际兼容性取决于设备对容器、视频编码、音频编码、10-bit 和 HDR 的支持。

如果“带字幕的视频无法播放”，请先看文件格式：字幕只是在画面上叠加，常见的真正原因是带字幕片源同时使用了浏览器不易直放的 MKV 容器或 FLAC/Opus 音频。新版播放页会显示实际兼容性提示，并默认先关闭字幕，让视频解码与字幕加载互不干扰。

LMD 会在启动或扫描后自动检查容器与音频组合。发现浏览器不易直放的 MKV、FLAC/Opus 等情况时，会自动加入兼容处理队列，无需手动点击：

- 视频使用 FFmpeg 的 `-c:v copy` 原样复制，不重新编码，画质不变。
- 10-bit 和 HDR 信息随原视频码流保留。
- 不兼容音频可以转换为 AAC 256 kbps；AAC 转换不是数学意义上的无损，但视频码流保持不变。
- 原始视频不会被覆盖；兼容副本默认写入 `data/cache`，也可以在运行设置中选择独立保存目录。
- 默认每次只运行 1 个任务；在本机管理端“运行设置”开启并行加速后，最多同时运行 3 个任务，并在 12 小时后自动恢复单任务模式。
- 手动关闭或定时到期不会强制中断已经运行的 FFmpeg，只会停止补充新的并行任务。并行加速会增加磁盘并发读写，副本所需空间通常接近原视频大小。
- 观看端在后台轮询处理状态；兼容副本完成后，已打开的播放器会自动切换到 MP4 + AAC 地址。
- 如果设备不支持原视频编码，仅重封装仍无法解决；当前版本不自动转码视频。

## 10 路播放能力

服务端最多允许 10 路音视频同时传输。电子书和表格的读取不占用这 10 路配额。原文件直传不会执行十次视频编码，主要消耗硬盘读取和局域网带宽；无损重封装也不会占用 RTX 3060 的 NVENC 编码资源。

在十代 i5、RTX 3060、16 GB 内存、2.5G 有线服务器和千兆无线网络基础上，架构面向 10 路 1080p 10-bit 直传。实际体验仍取决于视频峰值码率、硬盘并发读取、无线 AP、信号质量及客户端硬件解码能力。服务端的 Range 分段传输和 10 路限制已经验证，但尚未用十台真实设备完成长期压力测试。

## 代码目录，用生活化方式理解

```text
src/main.tsx          网页的“大脑”：管理页、观看页、视频播放器和字幕选择
src/music.tsx         音乐目录、播放队列、完整播放器、迷你播放器和滚动歌词
src/reading.tsx       阅读目录、PDF/TXT/电子书阅读器和虚拟化表格预览
src/reading-sheet.worker.ts  后台解析 Excel/CSV/ODS，主界面保持响应
src/styles.css        网页的“装修”：颜色、尺寸与手机/平板响应式布局
server/index.mjs      共享服务：本机管理限制、扫描、字幕提取和视频直传
server/music.mjs      音乐扫描、元数据、封面、歌词、Range 直传和无损兼容副本
server/reading.mjs    阅读目录扫描、权限过滤和电子书/表格 Range 直传
tray.ps1              系统托盘控制器：管理页快捷方式、二维码和共享服务启停
tray-qr.mjs           使用二维码组件生成托盘窗口中的二维码图片
启动LMD.vbs           Windows 双击入口；隐藏启动托盘，不出现 CMD 窗口
tools/ffmpeg/bin      读取媒体信息、提取字幕字体、重封装和转换 AAC（可在运行设置中自动安装/更新）
runtime/node.exe      运行 LMD 服务所需的内置 Node.js
data/state.json       视频/音乐/阅读目录、媒体记录、任务、访问控制和运行设置
data/cache            字幕、字体、封面、歌词及音视频兼容副本缓存
dist                  构建完成的网页文件
```

浏览器页面只是操作面板；“管理端只能在本机操作”和文件夹授权判断都由服务端执行。因此，局域网设备无法通过绕过网页按钮来执行管理操作或读取未授权的视频、音乐、电子书或表格。

## 页面打不开时

1. 在服务器电脑打开 `http://127.0.0.1:8096/api/health`。能看到包含 `"ok":true` 的内容，说明服务正在运行。
2. 手机不能使用 `127.0.0.1`，因为这个地址在手机上表示手机自己；必须使用服务器电脑的局域网 IP。
3. 确认两台设备位于同一局域网，并检查 Windows 防火墙是否允许 LMD 通过专用网络。
4. 局域网设备不能打开 `/admin` 是正常行为；管理端只能在服务器电脑本机打开。
