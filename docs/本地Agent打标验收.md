## 已确认的既有失败

`server/playback-integration.test.mjs:100` 在删除会话后等待 200ms，要求播放管线立即归零，实际仍为 1。使用同一 FFmpeg 对未修改的原目录执行该测试，也在同一断言失败。本次未改动播放核心以修复此既有问题，不把整套播放集成测试报告为通过。

## 使用边界

所有自动标题结果仅用固定模拟 Agent 在隔离数据中测试；没有为真实库启动 Agent 或提交测试标题。部署检查时真实库有 79 个待处理作品组。用户仍需在服务器电脑手动启动具备联网能力的 Agent，复制提示词和范围命令开始处理。

来源由 Agent 提供，LMD 校验格式、证据是否齐全和保护规则，不独立查证来源内容。标准季目录可合并为作品组；不明确的目录组织及季集对应应标待确认。其他候选功能未实现。
